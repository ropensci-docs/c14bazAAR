# Get information for c14 databases

Looks for information for the c14 source databases in
[db_info_table](https://docs.ropensci.org/c14bazAAR/reference/db_info_table.md).

## Usage

``` r
get_db_url(..., db_info_table = c14bazAAR::db_info_table)

get_db_version(..., db_info_table = c14bazAAR::db_info_table)

get_db_version_number(..., db_info_table = c14bazAAR::db_info_table)
```

## Arguments

- ...:

  names of the databases

- db_info_table:

  db info reference table
